# Ghi chú tuần 4

## 1. Một Script Selenium gồm 6 bước

1. Bước 1: Import thư viện
2. Bước 2: Khởi tạo trình duyệt
3. Bước 3: Mở trang web
4. Bước 4: Tìm phần tử và thao tác
5. Bước 5: Kiểm tra kết quả
6. Bước 6: Đóng trình duyệt

## 2. Quy tắc đặt tên của Pytest

- Tên file phải bắt đầu bằng `test_` và kết thúc bằng `.py` hoặc kết thúc bằng `_test.py`, ví dụ: `test_login.py`, `login_test.py`.
- Tên hàm test phải bắt đầu bằng `test_`, ví dụ: `test_login()`.
